# Hassan Photostat and Graphic Center

Responsive Urdu/English business website and local website manager built with React, TypeScript and Vite.

## Run locally
1. Install Node.js LTS.
2. Extract this ZIP and open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. Run `npm run build` to create the production site in `dist/`.

## Website sections
- Business header and introduction.
- All seven supplied services and prices.
- WhatsApp order and phone-call actions.
- Visible social/web links collected together on one page.
- Business hours and Dera Ismail Khan address.
- Responsive layout for mobile and desktop.

## Website manager
The side menu lets you add, hide/show, and delete links; change the business name, tagline, phone numbers and theme color; and generate a QR code for the current website address. These settings are stored in the current browser using localStorage.

## Important before publishing
- Replace the sample Facebook, Instagram and TikTok URLs with the real business page links in the **سوشل لنکس** section.
- Confirm the phone and WhatsApp numbers in **ڈیزائن سیٹنگز** before publishing. The starting values are carried over from the supplied project.
- The manager is a local prototype, not a password-protected online admin system. Browser-local edits do not automatically update the deployed website or sync to other devices. For a secure online admin panel, database, authentication and publishing workflow still need to be configured.
